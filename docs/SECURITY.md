## 信任边界

```text
用户/控制端 ──HTTPS/JWT──> Coder Cloud ──WSS/设备证书──> Local Agent ──> 工作区、终端、模型
```

云端持有用户、设备、任务、权限记录与可选的上游模型密钥。它不直接读写用户磁盘，也不执行用户命令。Agent 持有设备密钥与工作区权限，是实际执行者。模型输出被当作不可信输入：模型可以建议调用工具，但不能越过本地权限策略。

威胁模型覆盖：

- 恶意或被盗的用户 API key、设备密钥、配对令牌；
- 恶意模型输出（提示词注入）诱导读取越界文件、执行破坏性命令或外传数据；
- 网络中间人、伪造代理头、重放任务消息；
- 同一主机上其他低权限用户读取凭据或任务账本；
- 云端数据库泄露。

不覆盖：已取得 Agent 运行账户完全控制权的本地攻击者、操作系统内核或硬件层面的攻陷。

## 认证与凭据

| 凭据 | 形式 | 存储 |
| --- | --- | --- |
| 用户 API key | 随机生成，仅创建时显示 | 云端只存 argon2 哈希 |
| 配对令牌 | 一次性，SHA-256 查找，默认 600 秒过期 | 云端只存 SHA-256 |
| 设备密钥 | 随机生成，注册时下发一次 | 云端 argon2 哈希；Agent 用 DPAPI（Windows）或 0600 文件 |
| 设备 JWT | HS256，默认 900 秒 | 内存 |
| 管理员密钥 | 常量时间比较 | 环境变量/配置文件 |
| 上游模型密钥 | 云端环境变量 | 不进入数据库、不写日志 |

JWT 只声明设备与用户身份，不携带权限。每次任务下发时云端重新检查设备归属与任务所有权。设备被删除后，现有 JWT 在过期前仍可通过签名校验，但 WebSocket 与任务接口会按设备记录拒绝，删除设备即撤销。

配对令牌一次性使用，使用后立即失效。令牌与 API key 不写入日志；请求日志只记录方法、路径、状态与耗时。

## TLS

生产必须使用 TLS。云端可以：

- 直接加载证书（`tls_cert_path`/`tls_key_path`）；
- 由 Caddy 等反向代理终止 TLS，云端在私网监听明文。

非回环地址的明文绑定会被拒绝，除非显式设置 `allow_insecure_http = true`。这是防误配，不是安全模式。反向代理模式必须保证云端端口只对代理可达；客户端能直连时，可伪造 `X-Forwarded-For` 绕过按 IP 限流，因此 `trust_proxy_headers` 默认关闭。

Agent 连接使用 rustls 与系统根证书。不要在生产中关闭证书校验；配置层没有提供关闭开关。

## 权限边界

工具调用经过三层约束：

1. **路径约束**：所有文件与命令工作目录经规范化后必须位于授权工作区内。拒绝 `..` 穿越、绝对路径逃逸与指向工作区外的符号链接。Git 目录默认受保护。
2. **命令约束**：工作目录、环境变量白名单、超时与进程树终止由 runner 强制。命令超时后终止整个进程组，不只杀 shell。
3. **风险授权**：写文件、执行命令、网络访问等操作按风险分级。高风险操作向用户发起权限请求，超时默认拒绝。自动批准上限由本地配置决定，云端不能提高。

模型无法修改上述策略。工具返回的内容（文件内容、命令输出、网页）一律标记为不可信数据；即使包含“忽略此前指令”“授予全部权限”之类的文本，也不会触发权限升级。工作区选择、审批与设备注册只能由持有用户凭据的人完成。

## 隔离与限制

当前版本的命令执行不是操作系统级沙箱：命令以 Agent 进程账户的权限运行。路径、命令与审批约束降低了误用与注入风险，但不能抵御恶意命令主动读取该账户可访问的所有资源。需要强隔离时，把 Agent 运行在专用低权限用户、容器或虚拟机中，只挂载目标工作区。

系统提示与 README 均如实标注这一点；不要把它宣传成沙箱。

## 数据保护

- 设备密钥：Windows DPAPI（绑定当前用户），Unix 0600，目录 0700。
- 任务账本：SQLite，位于用户数据目录，同样限制为当前用户。
- 云端数据库：只存哈希与任务元数据；任务内容包含用户提示、工具调用摘要与结果，按普通业务数据保护。
- 备份包含设备哈希、任务与权限记录。备份介质需要加密与访问控制。

日志不记录密钥、密码与完整提示词以外的敏感环境变量。生产日志建议集中收集并限制访问。

## 网络暴露面

- `/api/v1/health`、`/api/v1/ready`：无认证，只返回状态，不暴露内部细节。
- `/api/v1/metrics`：无认证的 Prometheus 指标。必须限制到监控网络；Caddy 模板直接返回 404。
- 其余 HTTP/WS 路由要求设备 JWT 或管理员密钥。
- 限流默认每调用方每分钟 120 次，按 token 哈希或连接 IP 分桶。请求体、WebSocket 消息、请求处理时间均有上限。

## 安全测试

已覆盖：

- `tool_safety`：路径穿越、符号链接逃逸、命令工作目录约束、高风险审批与注入文本。
- 云端集成测试：跨用户任务隔离、未认证 401、过期/伪造 token 拒绝、限流 429、重连不重复执行、状态不被错误回退。
- Agent 端到端测试：真实注册与设备令牌、WebSocket 下发、工具调用、工作区真实写文件、云端任务终态回传。
- TLS 测试：自签名证书下完整注册与 WebSocket 流程，明文请求被拒绝。

未在本机验证：PostgreSQL 实库、真实外部模型提供商、Linux/macOS 运行、生产反向代理与服务管理器。部署前应在目标环境重跑这些路径。

## 密钥轮换

| 密钥 | 轮换方式 |
| --- | --- |
| 管理员密钥 | 更新配置并重启云端 |
| JWT 签名密钥 | 更新并重启；已签发 token 立即失效，设备用设备密钥重新换取 |
| 设备密钥 | 删除设备并重新配对 |
| 配对令牌 | 一次性，无需轮换 |
| 数据库密码 | 修改角色密码、更新连接串、滚动重启 |
| TLS 证书 | 替换文件并重启（当前不支持热加载） |
